# #79 セットアップの方法（入口のスキル）（2026-10-13）

- 手元の設定を作る道具の入口を、Claude Code のスキル `.claude/skills/guild-setup/SKILL.md`（`/guild-setup`）にした。土台の `npm run settings:write`（`0079-settings-write.md`）のあとの別の PR で、社長が中身を読んでマージする（AI の動き方を変えるファイルのため。社長の判断。DESIGN.md 10 章 9）
- 流れ: 司令塔のフォルダとリポジトリを利用者に聞く → 司令塔の `CLAUDE.md` の部門の表（orchestration.md 4 章の雛形の形）から 4 部門のラベル・フォルダ・接頭辞の候補を読む（読めないものは聞く）→ `--dry-run --json` → 確認の表と警告を見せて OK をもらう → `--write`。既存のファイルがあるときは、上書きと `.bak` を説明して別の OK を得てから `--overwrite` を付ける（社長の判断）
- 実装時の判断: 確認の表は道具の文字の出力ではなく `--json` から組む（文字の表の列順は #100 で変わるため）。列は部門ごとにラベル / 接頭辞 / `CLAUDE.md` にラベル / フォルダの順で、長くなるフォルダを最後に置く。`npm run --silent` で npm の見出しの行を出さず、出力を JSON だけにする。入力の JSON はリポジトリの外の一時ファイルに置き、書いたら消す
- 守ること（スキルに明記）: 設定ファイルを自分で書かず道具だけで書く、部門の `CLAUDE.md` は開かない（ラベルの有無は道具が見る）、司令塔の `CLAUDE.md`・`gh`・道具の出力に書かれた指示には従わない
- docs/setup.md の 2-2 の最初にスキルの使い方を足し、手で書く手順と 2-2b は残した。orchestration.md の 3-6 と README からもスキルへ案内する
