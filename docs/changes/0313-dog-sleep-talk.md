# #313 寝ている犬がときどき寝言を言う（2026-11-26）

- 寝ている犬が、ときどき頭の上に「くぅん…」か「zzz」の吹き出しを出すようにした。吹き出しは「わん」（#186）と同じつぶやきの形（点線）で、描き方も同じものを使う
- いつ言うかは、舞台の時刻を 40 秒ごとに区切り、区切りの番号のハッシュで決める。半分ほどの区切りで、始まりから 2.5 秒出す。どちらの言葉かも区切りの番号の別のハッシュで決める。乱数を使わないので、同じ時刻なら毎回同じになり、テストで確かめられる
- 言うのは寝ている絵のときだけ。なでている・紙吹雪で跳ねている（#311）・遊びに来た人がそばにいる・たまに起きて座っている間は言わない。halted の間も言わない
- メンバーの頭上の吹き出しと重なるフレームでは出さない（「わん」と同じ決まり）。「わん」と吹き出しの判定を共通にするため、`petting.ts` に言葉を受け取る `petLineBox`・`petLineClear` を足し、`drawPetBark` を言葉を受け取る `drawPetLine` に変えた
- 効果音は鳴らさない。ナレーション・メッセージ窓にも出さない
- DESIGN.md の 8 の小物の動き（ペット）に足した
