# #167 ラベルを部門と「社長」の間で付け替えたときに「とどいた」を出さない（2026-10-17）

- 開いている Issue のラベルを部門から「社長」に付け替えると、王様のクエストとして「おうさまに クエスト#N が とどいた！」と出ていた。差分は王様のクエストの番号の集合だけを比べていて、前回は部門の Issue だったことを見ていなかった
- 逆向き（「社長」から部門）も、部門の Issue としては基準に無い番号なので、部門にクエストが届いた演出（`issue-opened`）が出ていた。同じく直した
- 前回の基準で部門の open の Issue だった番号は、王様のクエストに現れても「とどいた」にしない。前回の基準の `king` にあった番号は、部門の open の Issue に現れても `issue-opened` にしない。判定は `domain/events.ts`（`kingQuestEvents` と `collectEvents`）
- 王様から外れた側の「クリアした」は、#142 で受け入れたとおり残す
- 閉じた部門の Issue を開き直して「社長」を付けたものは、新しく届いたものとして扱う（実装時の判断）
