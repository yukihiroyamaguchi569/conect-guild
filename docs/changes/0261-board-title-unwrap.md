# #261 掲示板のクエストにマウスを乗せたら題名の全文を出す（2026-10-27）

- 1 本目（PR #262）のブラウザ標準のツールチップ（`title` 属性）が、社長の環境で出なかった（場所・1 秒待つ・ブラウザが前面、の条件はそろっていた）。ページの側は、属性が付いていて、上に重なる部品も描き直しもないことを確かめた。OS が描くツールチップはこちらで撮れず、出ない原因は分からなかった
- そこで、マウスを乗せた行だけ題名を折り返して全文を出す形を足した（CSS の `:hover`。ページの中に描くので、どのブラウザでも出て、スクリーンショットで確かめられる）。行の高さは乗せている間だけ伸びる。`title` 属性は残した。DESIGN.md 4.1 の掲示板の項を直した
