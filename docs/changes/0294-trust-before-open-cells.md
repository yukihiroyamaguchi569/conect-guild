# #294 trial:open-cells で開いたセルが、信頼の画面で「No, exit」を選ばれて落ちる（2026-11-18）

- 新しいお試しの会社に `npm run trial:open-cells` を打つと、まだ信頼していないフォルダのセルが落ちた。MulmoTerminal の `spawnBackgroundChat` は必ず最初の指示を打ち込み、信頼の画面（既定が「No, exit」）でそれが「終了」と受け取られるため。conect-guild の側からは打ち込みを止められない
- Issue の候補 2 を入れた（社長の判断）: 開く前に、司令塔のフォルダが Claude Code で信頼済みかを `~/.claude.json`（`CLAUDE_CONFIG_DIR` があればその下）で読むだけで確かめ、未信頼なら何も開かず、司令塔のフォルダのセルを手で開いて信頼し、閉じてから打ち直すよう案内して止まる。信頼済みなら今までどおり全部開く
- `~/.claude.json` は Claude Code の内部ファイルなので、無い・読めない・JSON でない・形が違う（`projects` がオブジェクトでない、司令塔のフォルダか親の項目がオブジェクトでないか `hasTrustDialogAccepted` が真偽値でない）ときは今までどおり開く（悪くならない方へ倒す）。司令塔のフォルダか親の項目の形の違いを未信頼と数えて止めていたのを、codex のレビューの指摘で判定できないに直した。ほかのフォルダの項目の形は見ない。読むのは `projects` の各キーの `hasTrustDialogAccepted` だけで、ほかの値は保存も出力もしない。信頼済みの印を書き込む案は、利用者の Claude Code の設定を書き換えるので外した
- 親のフォルダの信頼も効くので、司令塔のフォルダか親のどれかが `true` なら信頼済みとする。部門のフォルダは司令塔のフォルダの下と決まっているので、司令塔だけを見る（実装時の判断）
- 判定は純粋関数 `packages/collector/src/claudeTrust.ts`、読み込みは `trialOpenCells.ts`。`docs/trial.md` の「あなたがやること」の 6 と、`/guild-trial` の 7-3 の案内を、初めては先に手で信頼してから打つ流れに合わせた
- 根本の修正（MulmoTerminal が信頼の画面の間は打ち込まない）は MulmoTerminal 側の課題として Issue に報告文を置いた
- 案内には司令塔のフォルダを `~` 付きで出す。これまでログにパスを出さなかったのは改行での偽装を避けるためで、このパスは `~/guild-trial/<お試しの名前>` の形と確かめたあとのもの（念のため `escapeForTerminal` も通す。実装時の判断）
- DESIGN.md の 10 章の「お試しの会社のセルをまとめて開く道具（Issue #223）」の項に足した
