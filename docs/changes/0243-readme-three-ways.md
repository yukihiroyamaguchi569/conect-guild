# README に 3 つの試し方を一覧で書く（Issue #243）

- README（日・英）に「試し方」（Ways to try it）の節を置き、デモ・架空の会社・自分のチームの 3 つを、手間の少ない順に 1 行ずつ並べた。3 つの節はその下の小見出しにし、1・2・3 の番号を付けた。docs/setup.md・docs/trial.md から README の「デモを見る」へのリンクを新しい見出しに直した（社長の指摘）
- デモの節から `?demo=1`（効果音つきで最初から見る・撮る）の段落を消した。初めての人は開くだけで自動のデモが流れるため。使い方は docs/DESIGN.md に残っている（社長の判断）
