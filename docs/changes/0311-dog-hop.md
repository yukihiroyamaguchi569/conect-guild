# #311 紙吹雪の間、犬がぴょんぴょん跳ねる（2026-11-26）

- クエストのクリアの紙吹雪が舞っている間、玉座の横のトイプードルがぴょんぴょん跳ねるようにした。新しい絵は描かず、起きた絵 `awake-poodle` を上下に動かすだけ
- 紙吹雪が舞っているかは、旗がはためくのと同じ手がかり（`DecorCues.clearedAt`）で決める。いちばん新しい紙吹雪の始まりから数えて、0.4 秒（`TRINKETS.hopMs`）ごとに 1 回、最大 3px（`TRINKETS.hopPx`）上がる。床から跳ね上がるだけで、下には沈まない。小さく跳ねるほうがかわいく、ほかの絵に重ならないため 3px にした（実装時の判断）
- 優先の順は、なでている間のしっぽ振り、跳ねる、遊びに来た人がそばにいる・たまに起きる、寝ている、の順。なでたときの反応を消さないため
- halted の扱いは旗と同じにした。halted の間はメッセージが進まないので新しい紙吹雪は出ない
