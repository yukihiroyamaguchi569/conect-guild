# #182 お客さんの席にベンチを置く（2026-10-18）

- 社長の要望: お客さんの席に椅子を置く。#179 で寝姿（座った絵）にしたお客さんが、青い敷物の上で宙に座って見えたため
- 案を 3 つ並べて見せた（すべて既存の素材）: A 机の椅子（タイルの `chair`）、B 丸いスツール（小物の `stool`）、C ベンチ（小物の `bench`）。A と B はお客さんの体に隠れて見えず、体より幅の広い C で社長の OK をもらった
- 描き方: お客さんの層で、体より先にベンチを描く（`drawGuests.drawGuestBodies`、位置は `guests.benchPoint`）。お客さんがいるときだけ出る。間取りのデータには入れないので、席が歩けるマスであること・席に小物を置かないことの決まり（layouts のテスト）と golden は変わらない
- 位置: 足元の真下から 12px 右（`GUEST.benchDx`）。真ん中だと、2・3 部門の酒場で丸テーブルの右のスツールに、4 部門で 1 人目のベンチが地図テーブルのスツール（6,12）に重なるため。既存の家具は動かしていない
- 立ち姿・うとうと・寝姿のどれでも、ベンチの前に立つか、ベンチに座って見える。こっくりや読むときの上下でもベンチは動かない
- 小物の絵（decor.png）が読めないときは、ほかの小物と同じ単色の箱になる（loadArt.ts の既存の扱い）
- テスト: `benchPoint` の位置、すべての間取りのお客さんの席でベンチが小物の絵と家具に重ならないこと（`guests.bench.test.ts`）、e2e でお客さんごとにベンチが体より先に描かれること、decor.png が読めなくてもお客さんが描かれること（`guests.spec.ts`）
