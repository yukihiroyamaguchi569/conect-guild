# #77 セリフの吹き出しを、四角ではなく話し手を指す吹き出しらしい形にする（2026-10-12）

- 吹き出しを、白い四角と 2×2 の点の尻尾から、角を 2 段の階段で丸めた白地・濃紺の縁・右下の影の形に変え、下辺から 4 段の階段の尻尾を話し手の頭へ傾けて出すようにした（4.12「吹き出しの形」）。社長の指摘「そもそも吹き出しって、四角いのは見たことない」「文字の周りの余白も少ない」による
- 案を 3 つ（A ドット角丸・B 意味で形を変える・C 黒い窓）画像で作って見比べ、社長が B をすべて採用した。ふだんは A の形、王様の「！」の呼びかけは叫び（黄色地・2px の縁・ギザギザ）、「ゴニョゴニョ」とつぶやきはささやき（点線の縁・灰色の文字）。記号の吹き出しも同じ形の小さな正方形にした
- 文字は 8px（案の 9px は少し大きいとの社長の判断。今までは 7px）、余白は横 3px・上下 2px。吹き出しの高さが 9px から 14px になったので、頭上のいちばん高い所（`OVERHEAD_TOP`）と「LEVEL UP」の文字の位置もそれに合わせた
- 巻物・宝箱を掲げてセリフを言うときは、吹き出しを物の横（頭の高さ）に置いて尻尾を頭へ向けるようにした。右 → 左 → 物の上の順に、ほかのメンバー・ほかの吹き出し・Lv のタグ・HTML の窓にかからない所を選ぶ（社長の判断）。物の上に出すときの持ち上げは、新しい大きさで尾が物にかからないよう 36px から 34px にした（吹き出しの下端が今までより頭に近いため）
- 調べた結果、受付のかなめの横には上の段の机のタグが、席のみのり・ひびきの横には玉座や窓があるので、そこでは物の上になることが多い。横に置けるのは、ひらめ・ささえが受付から席に戻って巻物を掲げたときなど。かなめが歩き去った瞬間に物の上から横へ移ることがある（フレームごとに決めるため）
- Canvas は整数でない倍率で拡大しているので、1 行ずつ `fillRect` で塗ると段の間に細い横線が出た（案の画像で見つけた）。1 色ごとに重なる長方形を 1 本のパスにまとめて 1 回で塗るようにした
- 関係する章: 4.10、4.12
