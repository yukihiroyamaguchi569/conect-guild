# #147 王様のクエストのクリアを紙吹雪なしの一言にする（2026-10-15）

- 社長の判断（2026-10-15、#140 のやりとり）で、王様のクエストのクリアは紙吹雪なしで「小さな一言だけ」にした。#145（#142）で入れた玉座の上の紙吹雪を外したので、紙吹雪がキャンバスの上端で切れる件（#147 のはじめの中身）も無くなった。玉座のそばに件数の巻物の小物は置かない
- 台本（`render/scenes.ts`）: `king-quest-cleared` は紙吹雪も動きも無く、王様が玉座で `kingClear`（「おわったぞ！」「やりとげた」「どうじゃ！」）を 2.0 秒、それが消えて 0.4 秒後にかなめが受付で `seeKingClear`（「さすがです」「おみごと！」「おつかれさま」）を 1.6 秒言う。セリフ帳（`render/lineBook.ts`）にこの 2 つの場面を足した。頭上の優先順位は出来事の一言。かなめは立ち止まっているときは正面を向く絵しか無いので、王様のほうへは向けていない
- 配役: 紙吹雪だけの出来事（`isClear`）から王様のクリアを外し、王様とかなめを配役にした。王様が前のクエストの巻物を掲げている間やかなめが玉座のそばから戻る途中なら、終わってからメッセージ・効果音と一緒に出す（遊びに出ていたかなめは受付に戻ってから言う）
- メッセージ窓の「おうさまは クエスト#N を クリアした！」と効果音（クリア）はそのまま
- テスト: vitest（台本のセリフと時刻、0.4 秒の間、紙吹雪が無いこと、セリフ帳の場面と文字の決まり、吹き出しがタグ・窓・画面の端と、みのりの吹き出しにかからないこと）。e2e の `kingQuestEvents.spec.ts` は、クリアで玉座の上に紙吹雪が無く、王様の一言とかなめの返しが出ることを確かめるように直した（開く演出を待つので、この 1 本の時間を 60 秒にした）
