# #281 動いている版のコミットのハッシュを取得のようすに出す（2026-11-18）

- いま動いている conect-guild がどの版かを画面で分かるように、取得のようすの窓（タブ）の「最終取得」の行の右に、コミットの短いハッシュを小さく出した。ツールチップは「このコミットで動いています」。行は増やさず、窓は高くならない。デモでも出す。置き場は社長の判断（右下の隅に固定する案は採らない）
- ハッシュは `apps/web/vite.config.ts` の読み込み時に `apps/web/commit-hash.ts` の `readCommitHash` が `git rev-parse --short HEAD` を `execFileSync` に引数の配列で渡して取り、`define` の `__COMMIT_HASH__` で埋め込む。ブラウザからは何も取りに行かない
- git が無い・リポジトリでない・失敗した・ハッシュらしくない出力のときは null にし、何も出さない。ビルドも開発サーバーも止めない。実行の部分は注入でき、成功と失敗を vitest で守る
- 開発サーバーは起動したときのハッシュを出し続ける。コミットを進めたら開発サーバーを立て直すと新しいハッシュになる
