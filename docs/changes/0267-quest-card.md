# #267 掲示板のクエストを押すとカードが出る（2026-11-08）

- 掲示板の王様・受付・部門の行をボタンにし、押すとそのクエストのカード（DESIGN.md 4.18）を画面の上に出すようにした。お客さんの行は変えていない
- カードの中身は `app/questCard.ts` の純粋関数で決める。担当は掲示板の欄から引くので、掲示板と同じ決め方になる。M/D の文字のために `domain/deadline.ts` に `monthDayAfter` を足した
- 締め切りの文は、当日を「きょう」、過ぎたものを「N 日 すぎた」にした（「あと 0 日」「あと -1 日」を避けるため。実装時の判断）
- 見せるモードではカードの題名も伏せる（4.14 に追記）
- めくり・効果音（#268）と絵（#269）は入れていない
