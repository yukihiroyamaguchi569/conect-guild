# #269 クエストのカードに codex の絵を入れる（2026-11-08）

- クエストのカード（#267・#268）の枠・裏面・挿絵を、codex が生成した絵（社長が選んだ案 B）に替えた。素材は `assets/card/`（WebP、合計約 710KB）、出所とライセンスは `assets/README.md`
- 部門の枠は灰色の金属と巻物の 2 枚に分け、金属だけに担当の色を付けた（巻物ごと色を付けると羊皮紙の色まで変わるため）。色は淡いまま（社長の判断）
- 王様のクエストは金色の王冠の枠。挿絵は担当メンバーの絵（受付はかなめ、王様はゆきひろ）を窓に合わせて切る
- 「とじる」は巻物に入らないのでカードの下に出した。レア度の光は枠の形に沿う drop-shadow にした
- 部品の位置と絵の選び方は `app/questCardArt.ts`。担当の情報に、顔の色の代わりにメンバーの id を持たせた
- 絵の作り方のスクリプト（`assets/card/*.mjs`）は手で動かすものなので、ESLint の対象から外した。生成した元の画像と途中の部品は `.gitignore` に入れた
