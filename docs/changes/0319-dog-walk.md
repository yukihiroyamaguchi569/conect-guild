# #319 犬がごくたまにギルドを散歩して戻る（2026-11-27）

- 犬がごくたまに、玉座の横の自分の場所から通路を歩いて、窓の下か誰かの机のそばまで行き、1.5 秒（`TRINKETS.petWalkStayMs`）止まって、同じ道を戻るようにした。歩く絵は横向きの 2 コマ（`walk-poodle-a`・`walk-poodle-b`、#316）で、左へ歩くときは左右反転する
- 道筋は間取りから一度だけ作る（`render/petWalk.ts` の `petRoutesIn`）。行き先は窓の下（`windowTilesIn`。遊びに行くメンバーと同じ）と、各机の席の左右で歩ける側のマス。道は `findPath` で通路だけを通り、歩き方は訪問者と同じ `walkSegment`・`poseOnSegment`（1 マス 0.25 秒）
- いつ歩くかは寝言（#313）・骨（#318）と同じ作り方にした。舞台の時刻を 4 分（`TRINKETS.petWalkSlotMs`）の区切りに分け、区切りの番号のハッシュ（`hashStep`、別の値を足す）で 5 分の 1（`TRINKETS.petWalkShare`）の区切りを選び、区切りの始まりから歩く。行き先は区切りの番号で順に回る。舞台の時刻はページを読み込んだときに 0 から始まる（`performance.now()`）ので、読み込んでから最初の 2 区切り（8 分、見えていない間は進まない）は歩かない
- 散歩中は元の場所は空になる（絵がずれて描かれる）。押せる範囲も犬について動く（`Presses.petAt`・`sleepTalk.petAt`）。元の場所を離れている間は、メンバーより後ろに描かれるので、押す順もメンバーの後ろにする（`pressablesWith`。机のそばで、見えているメンバーを押して犬をなでることがないように）。キーボードのボタン（「犬をなでる」）は元の場所のまま（訪問者のボタンが扉の上のままなのと同じ）
- 優先は、回る（#312）、なでている、吠える（#317）、跳ねる（#311）、乾杯（#315）、お言葉を聞く（#314）、遊びに来た人がそばにいる、散歩、骨（#318）、たまに起きる、寝ている、の順。誰かが遊びに来たり、上の優先のものが始まったりしたら、散歩をやめて元の場所に戻る。散歩は時刻だけで決まる純粋関数で状態を持たないため、歩いて戻らずその場で元の場所に戻る（実装時の判断）
- 散歩中は寝ている絵ではないので、寝言は言わない
- 効果音・ナレーション・吹き出しは足さない
- DESIGN.md の 8 の小物の動き（ペット）に足した
