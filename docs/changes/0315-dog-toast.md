# #315 金曜の乾杯の間、犬が起きて座り、乾杯で「わん！」と言う（2026-11-26）

- 金曜の夕方の乾杯（#193）の間、玉座の横の犬が起きて座るようにした。メンバーがジョッキを掲げて「かんぱーい！」と言った時刻から 2 秒、犬も「わん！」と 1 回言う。新しい絵は描かない
- 乾杯の最中かどうかは、台本（`Director`）から読む。乾杯のトラックだけがジョッキを持つので、誰かのいまの区間がジョッキを持っていれば乾杯の最中とする。帰りの歩きはジョッキを持たないので含まない。「かんぱーい！」の時刻は台本のセリフから読む（`toastCueAt`）。乾杯の状態を部屋（`Room`）から渡す仕組みを足さずに済み、乾杯から外れた人の分も台本から消えるのでそのまま元に戻る
- 小物の動きの手がかり（`DecorCues`）に `toasting` と `cheeredAt` を足し、`cast.stageAt` で毎フレーム決める
- 「わん！」の吹き出しは寝言（#313）と同じ描き方で、メンバーの頭上の吹き出しと重なるフレームでは出さない。halted の間は出さない
- 優先は、なでている（しっぽを振る）、紙吹雪で跳ねる（#311）、乾杯、お言葉を聞く（#314）、遊びに来た人がそばにいる、たまに起きる、寝ている、の順。なでている間の言葉は「わん」のまま
- 月の集まり（#214）はジョッキを持たないので、犬は起きない（依頼が金曜の乾杯だけのため）
- 効果音・ナレーションは足さない
- DESIGN.md の 8 の小物の動き（ペット）に足した
