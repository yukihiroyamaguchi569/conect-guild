# #164 ラベルの無い Issue を、結び付いた PR の接頭辞で部門に置く（2026-10-17）

- 部門のラベルを付けない運用の会社では、Issue がすべてかなめの受付に積まれ、部門は何もしていないように見えた。PR はすでに、結び付いた Issue のラベルで決まらなければブランチ名の接頭辞（`branchPrefixes`）で部門が決まっていたが、Issue は接頭辞を見ていなかった
- 案 A（接頭辞から部門を決める）を採った（社長の判断、2026-10-17）。題名の書き方から決める案 B、スキルがラベルをまとめて付ける案 C は、あとで決める
- 部門のラベルがある Issue は今までどおりラベルで決める。ラベルが無い開いている Issue は、結び付いた開いている PR の接頭辞が 1 つの部門にそろったときだけその部門に置き、PR が無い・当たらない・割れるときは受付のまま
- 接頭辞の判定は PR の担当（`assignPr`）と同じ `departmentFromBranch` を使う。接頭辞が部門に当たらない PR は「割れる」に数えない、閉じた Issue は今までどおり受付、は実装時の判断
- 掲示板の欄だけでなく、メンバーの working・受付の件数・Issue が開いたときの手渡しの演出も同じ判定にそろえた（画面の中で置き場所が食い違わないように）
