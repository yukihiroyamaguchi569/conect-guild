# #176 題名の「@M/D」（やる日）を読み、その日まで掲示板に出さない（2026-10-17）

- 社長の要望: 題名の印を 2 種類にする。#174 の「〆M/D」（締め切り）に、「@M/D」（やる日）を足し、その日まで掲示板（ちかいもの）に出さない
- `@M/D` は 〆 と同じ読み方・年の決め方（`domain/deadline.ts` の `daysToDoDay`）。全角の `＠` も読む。`@` の後ろが M/D でないもの（メールアドレス、`@username`）は印ではない
- 「ちかいもの」の判定（`isNearQuest`。もとの `isNearOrNoDeadline` を改名）: やる日が来るまで出さず、来たら閉じるまで出す。〆 と @ の両方があればどちらかで出せるなら出す。〆 の 7 日の判定は変えない
- 隠した件数の文を「ほか N 件（締め切りが 先）」から「ほか N 件（日付が 先）」に変えた（やる日で隠れた分も入るため。分けずに最小限にした）。ボタンのツールチップにも @M/D を足した
- 限界（codex の統合レビューの指摘）: 年は取得の日にいちばん近い年なので、やる日から半年ほど開いたままの Issue は翌年の日と読まれ、また隠れる（#174 の過ぎた締め切りも同じ）。直すには年を Issue の作成日から決める必要があり、決め方が変わるので今回は入れず、テストで今の振る舞いを固めた
- docs/orchestration.md の司令塔の CLAUDE.md の雛形の 1 行に `@M/D` を足した
- DESIGN.md の 4 章「締め切りで絞る（Issue #174）」の次に追記した
