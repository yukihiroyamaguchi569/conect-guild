# #183 お客さんも部下と同じ時間でうとうと・寝るようにする（2026-10-18）

- 社長の要望: 「お客さんも部下と同じ挙動にして、必要なら絵を足して」。範囲は「時間で寝るまでを同じにし、席からは動かない（遊び場へは行かない）」を選んだ
- いままでは休憩中・待機中になるとすぐ寝姿（コマ 7 と「Z」、#179）だった。メンバーと同じく、仕事が無くなってから 10 分は前を向いて立ち、10 分でうとうと、30 分で寝姿にした。しきい値と動きはメンバーの `IDLE` の値と `idle.ts` のうとうと（こっくり・あくび・「…」）をそのまま使う（`dozeMotion` を切り出して共有）。「…」は「?」と同じ場所・同じ形に出すので、窓・「Lv N」・家具にかからないことは「?」の確かめで足りる。あくびの横向きのコマを左右反転して描けるようにした
- 起きて立っている姿は正面のコマ 0。既存のコマで足りるので絵は足していない
- 「最後に仕事があった時刻」はメンバー（`app/lastActive.ts`）と同じ決まりで、`app/guestLastActive.ts` に持つ。localStorage には番号の順の時刻だけを置き、名前・フォルダは残さない。判定（`render/guests.ts` の `guestLook`）は壁の時計を注入する純粋関数
