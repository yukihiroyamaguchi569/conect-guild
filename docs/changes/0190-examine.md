# #190 小物をクリックすると調べたメッセージが出る（2026-10-18）

- 社長の「他には何があるかな？」に出した案から、「宝箱・たるを調べる（月の飾りとも関連する）」を採用。王様・犬のクリックの仕組み（`render/clickables.ts`）に乗せた
- 調べられる小物は、間取りに置いてある収納の小物（たる・きばこ・ほんだな・つぼ・きんこ・ふくろ・しょるいだな）。宝箱の絵（`chest`）はどの間取りにも置いていないので押せない。置き場所を足すのは頼まれていないので見送った（実装時の判断）
- 文はメッセージ窓のナレーションの代わりに出す。出来事のメッセージが出ている間は捨てる。出来事の演出とメッセージの送り（`app/messageQueue.ts`）に手を入れずに済み、出来事を邪魔しないため（実装時の判断）
- キーボードは、小物が間取りによって 10〜12 個あり、1 個ずつ Tab で止めると多すぎるので、まとめて Tab の 1 か所にし、矢印キーで選ぶ形にした（実装時の判断）
- 窓に重なる小物は外した。押しても窓に当たるため
- 文の形（`PressLines`）は、あとで足す月の飾りも同じ形で持てるようにした。月の飾りそのものは作っていない
- DESIGN.md の 4.9 と 8 章に足した
