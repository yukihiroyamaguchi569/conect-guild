# #224 集まりの最中のレベルアップで「LEVEL UP」が遅れる（2026-10-19）

- CI の e2e「デモの 1 周目にレベルアップが出る」（`demo.spec.ts`）が、15 時台（日本時間）にだけ落ちた。メッセージ「かなめは レベル 6 に あがった！」は出るのに、Canvas の「LEVEL UP」が 5 秒以内に出ない
- 原因: 月の集まり（#214）の時間帯は、デモを始めた時点で手の空いた人が飾りの前に集まっている。かなめが集まり中のひらめにクエストを渡す場面では、ひらめが席へ歩いて戻るのを待ってから場面が始まる（乾杯 #193 と同じ決まり）。メッセージの列はこの戻りを知らず、場面がメッセージと同時に始まった前提で次のレベルアップのメッセージを出していた。そのため、Canvas ではかなめがまだ渡しに行っている最中で、跳ねる演出と「LEVEL UP」が約 6 秒遅れた
- 本物の画面でも、集まり（乾杯・月の集まり）の最中に場面が来れば同じずれが起きる。そのため、デモの台本で集まりを止めるのではなく、列を合わせる直し方にした
- 直し方: 場面の人を集まりから抜けさせたとき、場面の人それぞれが空くまでの時間を Canvas から列に伝える（`onAway` → `away` → `MessageQueue.occupy`。#87 で王様のもとへ行くかなめを待つのと同じ道）。列は次のメッセージをそこまで待つので、レベルアップのメッセージ・音・跳ねる演出がそろう。集まりから誰も抜けない場面では何も伝えず、これまでと同じ
- クリア（issue-closed）の担当を集まりから戻すときは、帰席までではなく紙吹雪が終わるまでを伝える。紙吹雪は担当が戻るのを待たずに席の上で始まるので、帰席までだけを伝えると、同じ担当の次の場面がクリアの演出と重なる（codex のレビューの指摘）
- 回帰テスト: `idleCrew.freeIn.test.ts`（集まりからの戻りの分だけ空く時刻が遅れること、クリアでは紙吹雪の長さまで伝えること）と、`demo.spec.ts` に時刻を固定した 2 件（月曜 15:30 の月の集まり、金曜 18:30 の乾杯）
- e2e は、メッセージが出た時刻と「LEVEL UP」が初めて描かれた時刻をページの中で記録し、差が 500 ms 未満であることを確かめる。描いた文字の記録は過去の分も残るため、出たかどうかだけを見ると遅れても通る（codex のレビューの指摘）。金曜の乾杯では直す前の遅れが約 0.75 秒なので、1.5 秒では直す前のコードでも通ってしまう。500 ms にした
- 残り: 列がレベルアップの人を呼び戻したあと、メッセージが出るまでの間に集まりが始まり、その人が加わることはまだありうる（1 日 1 回の始まりと重なったときだけ）。今回は直していない
