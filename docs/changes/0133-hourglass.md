# #133 砂時計の置き場所をカウンターの上にそろえる（2026-10-15）

- 砂時計（社長の承認まちの合図）を、部門の数にかかわらず、かなめのカウンターの上（列 17、8 行目。花びんの左隣）に置くようにした（社長の判断、2026-10-15）。これまでは 2・3・4 部門がささえの机の右端（列 22、11 行目）、5・6 部門がカウンターの上だった（#115 で 5・6 部門を作ったときの名残）
- カウンターの砂時計は smallRoom.ts の `roomWith` の動かない小物に入れた。#123 で残した `hourglassOnCounter` の値と、それを見ていた分岐（slots.ts の `buildLayout`、layout2〜6.ts）を消した
- ささえの机の列 22、11 行目には、5・6 部門と同じく巻物の山を置いた。これで 5・6 部門の見た目と golden は変わらない（実装時の判断）
- 2・3 部門の golden は、砂時計の行（(22,11) → (17,8)）と巻物の山の行（(22,11)）の 2 か所だけ変わった。4 部門の golden（`layout4.txt`）は、砂時計と巻物の山の行に加え、それに連なる行が変わった: 手前の重なりの層（カウンターの層に砂時計、総務の机の層に巻物の山）、止まった小物の一覧（巻物の山）、動く小物の一覧（砂時計が地球儀より前に来たため、砂時計・地球儀・ランタン・書類の山の位相が 377 ms ずつずれた）
- 砂時計の演出（承認まちで砂が落ちる）は置き場所によらず `hourglass` の名前で決まるので、そのまま動く。decor.test.ts に「砂時計は (17,8) で砂が落ちる」、layouts.test.ts に「どの間取りでも砂時計はカウンターの (17,8) に 1 つだけ」を足した
