# #120 パーティのようすのアイコンを髪の色で塗る（2026-10-15）

- パーティの窓の名前の頭文字の丸を、設定の色（`color`）からキャラの髪の色に替えた。社長の判断で、案の画像は社長の OK 済み
- 髪の色は `apps/web/src/domain/faceColor.ts` の表に置いた: かなめ #73447a、みのり #c3adbe、ひびき #f3899a、ひらめ #3e64a3、ささえ #5c7a52、たくみ #794f3d、むすび #594f56、ゆきひろ #ebeae7。スプライト（正面と右向きのコマの上 30 行）の髪の色相の画素を明るさの順に並べ、真ん中の 2 割を平均した中間の色。スプライトを描き直したら測り直す
- 文字の色は、WCAG 2.x のコントラストが高いほうの白か黒にした（同じなら白）。どの丸も大きな文字の AA（3:1）を超える。黒い文字に合わない文字の影はやめた
- 丸の白い縁は全員そのまま。ゆきひろの丸は髪が白に近く縁と見分けにくいが、社長の決定で今のままにした
- 設定の色は掲示板の欄の点にそのまま使う（変えたのはパーティの窓のアイコンだけ）
- vitest: 表の色がメンバー全員分そろうこと、明るさとコントラストの計算、白と黒の切り替わる境目、パーティの行が設定の色でなく髪の色を使うこと。E2E: 2・3・5・6 部門の架空の設定で、どの行の丸も髪の色と決めた文字の色で描かれること（`e2e/departments.spec.ts`）
