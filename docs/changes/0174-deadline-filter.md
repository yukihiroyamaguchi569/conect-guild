# #174 掲示板を締め切り 1 週間以内と締め切りなしに絞る（2026-10-17）

- 社長の要望: 掲示板のクエストを、締め切りが 1 週間以内のものと締め切りの無いものだけにし、ボタン 1 つで「すべて」と切り替えたい。締め切りは題名に「〆M/D」で書く（社長の選択）
- 題名の 1 つ目の `〆M/D` を `domain/deadline.ts` の純粋関数で読む。年は取得の日（`fetchedAt`）から見ていちばん近い年にする。どの年にも無い日（2/30）は締め切りなし。〆2/29 はいちばん近いうるう年の日にする（codex の指摘）。ちょうど半年で並んだときは来るほうにする（実装時の判断）
- 絞るのは掲示板の一覧（王様の欄を含む）だけ。机の巻物・メンバーの状態・受付の件数・演出・お客さんの欄は変えない
- 隠した件数は一覧の最後に「ほか N 件（締め切りが 先）」と出す（お客さんの欄の「ほか n 件」に合わせた）
- 切り替えは localStorage の `conect-guild:board-filter` に `{ "show": "near" | "all" }` だけを残す。デモではメモリ
- デモの架空の題名 2 つに 〆3/31・〆9/30 を付けた
- docs/orchestration.md の司令塔の CLAUDE.md の雛形（指示書を Issue に書く）に、締め切りを題名の頭に `〆M/D` で付ける 1 行を足した
