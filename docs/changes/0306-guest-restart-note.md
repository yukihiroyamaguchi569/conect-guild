# 設定を書き換えたあと、画面が先に変わっても起動し直すと書き分ける（Issue #306）

- お客さんを足したあと、`npm run dev:all` を起動し直す前に席が画面に出た。画面（Vite の開発サーバー）は読んでいる設定ファイルの書き換えを見てすぐ読み直すが、collector は起動したときにだけ設定を読む。文書には「collector と画面は起動時に設定を読む」とあり、実際と違った
- `docs/settings.md`（1 章の書き換えたあと、3 章のお客さん）、`docs/orchestration.md`（部門を変えたあと）、`/guild-setup` スキルの案内を直した。起動し直す手順はそのままで、席や名前が先に変わって見えても、Issue・PR・セッションの動きは collector を起動し直すまで前の設定のままだと書いた。どちらの設定ファイルを読むかは画面も起動したときに決めるので、`guild.settings.local.json` を作ったり消したりしたときも起動し直すと書いた
