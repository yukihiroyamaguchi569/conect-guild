# #165 王様のつぶやきの途中で承認まちになったら、つぶやきをすぐ終える（2026-10-17）

- 王様のつぶやき（`kingWork` など）の途中で承認まちになっても、新しいつぶやきを止めるだけで、言っている途中のつぶやきは最長 2.4 秒（`LINES.murmurMs`）残り、ページの「承認まち」の吹き出しと同時に出ていた。王様の承認まちはページの HTML の吹き出しで、Canvas の待ちの記号（`bubbles`）には入らないため、頭上の優先順位でも隠れなかった
- つぶやきを進める純粋関数（`render/murmurs.ts` の `stepMurmurs`）が、話し手が王様で承認まち（Canvas に渡る暇の時刻が無い）になったフレームで、出ているつぶやきを捨てるようにした。次のつぶやきの予定は、捨てたつぶやきの終わりから数えたまま（実装時の判断）
- 王様以外のつぶやきは今までどおり最後まで出す
- DESIGN.md の 4.12「つぶやき」の「言える人」を直した
