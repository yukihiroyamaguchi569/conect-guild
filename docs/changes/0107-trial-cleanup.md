# #107 お試しの会社を片付けるスキル（2026-10-15）

- `/guild-trial` で作ったお試しの会社を片付けるスキル `/guild-trial-cleanup`（`.claude/skills/guild-trial-cleanup/SKILL.md`）を足した（10 章 9）。Issue #107 の「片付け」の部分（「作る」は #136）
- 道具は作らず、スキルの手順に沿って Claude が `gh repo delete <owner>/<名前> --yes`・`rm -rf "<絶対パス>"`・`rm` を直接実行する（司令塔の指示）
- 片付けるものは、`~/guild-trial/` の下の `<日付>-<4 文字>` の形のフォルダと、`guild.settings.local.json` の `repo`・`commanderSessionDir` がその置き場を指しているかで見つける。候補が複数なら番号で選んでもらう（司令塔の指示）
- 消すものの一覧を見せて 1 回だけ承認をもらってから、リポジトリ → フォルダ → 設定の順に消す。途中で失敗したら止まり、どこまで消えたかを伝える（司令塔の指示）
- 本物の会社を消さないため、名前の形に合うものだけを扱い、`guild.settings.local.json` は `repo` がお試しのリポジトリと一致するときだけ消す（司令塔の指示。`commanderSessionDir` も見るのは統合レビューの指摘）。`.bak` も、中の `repo` と `commanderSessionDir` が同じお試しを指すときだけ消す（本物の会社の控えが残っていることがあるため。実装時の判断）。public のリポジトリはお試しではないとして消さない（お試しは private で作るため。実装時の判断）
- 名前の形だけでは消さない。フォルダは司令塔の `CLAUDE.md` に `/guild-trial` の道具が書く「架空の会社「お試し商会」」があるときだけ、リポジトリはそのフォルダの `origin` か手元の設定が指しているときだけ、お試しと見なす。置き場（`~/guild-trial`）や対象のフォルダがシンボリックリンクなら消さない。承認のあと、消す直前にもう一度確かめ、一覧と違えば止まって承認を取り直す（統合レビューの指摘）
- フォルダを消す 1 行に、置き場と対象がシンボリックリンクでないことの確かめを入れた（確かめてから消すまでの間の入れ替わりを狭めるため）。手元の設定や `.bak` を「無い」以外の理由で確かめられないときは止まる。承認の一覧に「自分の仕事に使い始めていたら言ってほしい」と添える（統合レビュー 2 周目の指摘）
- 承認の一覧で、お試しのフォルダのコミットの数とコミットしていない変更を見せ、作ったあとに手が入っていれば書き添える。フォルダを消す 1 行は初めから sandbox の外で実行し、失敗してからのやり直しをしない。リンクの確かめは間を狭めるだけで完全ではないと手順に書いた（統合レビュー 3 周目の指摘）
- `gh repo delete` に要る `delete_repo` の権限が無いとき（`HTTP 403`・`delete_repo`）は、`gh auth refresh -h github.com -s delete_repo` を利用者自身に実行してもらい、やり直す
