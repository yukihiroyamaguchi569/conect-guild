# #144 見せるモード（題名を伏せる）（2026-10-15）

- 人に画面を見せる・配信に映すときのために、題名だけをボタン 1 つで `＊` に伏せる見せるモードを足した（社長の要望）。DESIGN.md 4.14 を新しく書き、4.8（ボタンの場所）と 4.11（デモでは伏せない）から参照した
- 社長の判断: 伏せ字だけ（ぼかし・空白は作らない）、番号は隠さない、名前は隠さない、切り替えは「最終取得・音」のタブのボタン 1 つ（URL・キー操作は作らない）。localStorage に残す・伏せ中の小さな印・デモでは何もしない、は Issue の本文のまま
- 伏せ字の数は題名の文字数を 4〜8 に丸めたもの（実装時の判断。長さで題名を推し量られにくく、掲示板の幅にも収まる）。全角の `＊` にしたのは、日本語の題名と幅が近いため
- メッセージの行は、積むときに伏せた文も一緒に作って持たせ、窓に出すときに選ぶようにした（実装時の判断）。押す前に積んだ行・いま出ている行も、押した瞬間に伏せ字になる。王様のクエストの 2 文を含め、文の言い回しは変えていない
