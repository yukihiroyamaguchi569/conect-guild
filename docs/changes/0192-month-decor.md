# #192 毎月その月らしい飾りを置き、クリックで説明を出す（2026-10-18）

- 社長が遊びの機能の案から「毎月その月に特徴的なものを部屋に置き、クリックで説明」を選んだ。絵は #199 で入れた 12 種をそのまま使い、説明の文は社長に見せて OK をもらったもの
- 置き場所は、2〜6 部門のどの間取りにも空いている右の壁ぎわの床（パーティの窓の下、総務の机の右）に 1 か所決め、どの間取りも同じにした（間取りごとに探したが、ここがどれでも歩く道・席・窓・待ちの吹き出しにかからず、部屋の中から目に入るため。実装時の判断）。2×2 マスを歩けないマスにした。2・3 部門ではそこが歩けるマスだったが、行き止まりの端で、席・遊びの行き先・お客さんの道には使っていない
- 月が変わる飾りはキャッシュの背景に入れず、毎フレーム描く。描くたびに月を読むので、画面を開いたまま月をまたいでも次の月の飾りになる（キャッシュを作り直す仕組みを足さずに済むため）
- クリックは #190 の調べる小物に乗せた。#190 の `PressLines` の形のとおり、Canvas が押したときの月の文を渡す（`examineLineFor` とナレーションの `examine` は小物の種類ではなく文を受け取るようにした）。ボタンの名前は「かざりを しらべる」
- DESIGN.md の 3 章（構成）と 8 章に足した
