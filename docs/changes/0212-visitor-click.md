# #212 訪問者をクリックすると役ごとの返事をする（2026-10-18）

- 社長が遊びの機能の案から「訪問者をクリック」を選んだ。#213（ごほうびのクリック）の上に積み、押せるものの仕組み（`render/clickables.ts`）に乗せた。絵は足していない
- 返事は種類ごとに固定の 3 つ（`VISITOR_REPLIES`）。依頼の例の「なにか かうかい？」「いそがしいんだ！」「いっきょく どう？」「みらいが みえる…」は 7 文字・空白なしの決まりに合わないので、「かうかい？」「いそがしい！」「いっきょく？♪」「みらいが…」などにした。直前の返事は選ばない（`replyOf`）
- 返事は歩きながら頭上に 2.0 秒。訪問者の動きは変えない。話している最中に押したら、話している言葉を優先して捨てる（後から出すと、帰り道に急に返事をしてわかりにくいため。実装時の判断）。引き返している訪問者も「もう話さない」ので捨てる
- 当たり判定は、直前に描いたフレームの足元から（#191 のメンバーと同じ）。ごほうびの後ろ、メンバーの前
- キーボードは、訪問者がいる間だけ扉の位置にボタンを 1 つ出した。動く訪問者にボタンを付いて回らせると毎フレーム画面の部品を作り直すことになるため（実装時の判断）。来た・帰ったはループの `onVisitor` で知らせる
- 扉のそばで返事をすると吹き出しが画面の右端からはみ出したので、右にはみ出すときは左に出すようにした（`visitorWordsSide`）。席での言葉は前から端にかからない
- ループの関数が行数の上限を超えないよう、訪問者のクリックの受け口は `visitorStage.ts` の `visitorControls` に置き、ループではお客さんの分とまとめて `roomControls` で足した
- DESIGN.md の 4.15 に足した
