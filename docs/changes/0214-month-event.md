# #214 月の飾りに合わせて毎月その月らしい出来事を起こす（2026-10-18）

- 社長が遊びの機能の案から「月の飾りに合わせた出来事」を選び、範囲は「12 か月、絵なしで」とした。毎日 1 回、手の空いた人が月の飾りの前に集まり、その月らしい一言を言う
- 乾杯（#193）の仕組みを使い回した。乾杯の舞台を「集まりの決まり」（保存の鍵・時刻の判定・段取り）で組み立てられるようにし（ふるまいは変えない整理のコミット）、月の集まりはその決まりを 1 つ足しただけにした。歩きの段取り（`walksTo`・`timed`）も乾杯と共有した
- 時刻は 15〜18 時にした。金曜 18 時からの乾杯と重ならないため（実装時の判断。両方を始められるときは乾杯を先に見るが、時刻の幅が重ならないので実際にはどちらか一方）
- 集まる人の条件・保存（日付だけ、zod）・待つ条件・抜け方は乾杯と同じ。保存の鍵は `conect-guild:month-event-day`
- 飾りの真下は家具で歩けないので、その下の通路の、飾りに近いマスから並べた
- 一言は 7 文字の決まりに合わせ、12 月の例の「メリークリスマス！」（9 文字）は「メリクリ！」にした
- 飾りが右の壁のそばにあるため、頭上の言葉が画面の右端からはみ出した。セリフの吹き出しの左右の選び方（`overheadSide`）に「右端からはみ出すときは左」を足した（ほかの場面の吹き出しで今まで右にはみ出していたものがあれば、それも左に出る）。#212 の訪問者の `visitorWordsSide` と同じ考え方
