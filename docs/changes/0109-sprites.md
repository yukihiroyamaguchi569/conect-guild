# #109 絵: 新しい部門メンバー 2 人とお客さんのキャラを描く（2026-10-14）

- 部門 2〜6（#18）とお客さん（#108）のために、キャラを 4 体足した。たくみ（開発、#00897b）、むすび（営業、#ff7043）、旅の剣士（guest1）、旅の魔法使い（guest2）。名前と役割は、社長から任された司令塔が決めた（#109 のコメント）
- 絵は、いまの 6 体と同じく codex で描いた。いまのシートを手本に渡し、画風・コマの並び（7 コマ）・大きさをそろえた。手袋をはめた案は、肌の色で手の位置を測れないので描き直した
- `assets/sprites/build_sprites.py` は、メンバーの並びを `--members` で受け、別のシートの縮尺を `--scale-from` で使えるようにした。いまの 6 体は、引数なしでも前と同じバイト列になる
- 持つコマの手の位置は、新しい `measure_hands.py` で測り、`hands-new4.json` に置いた。コードへの取り込み（`hands.ts`）は、メンバーの id を足す #18 の工程で行う
- 出所は `assets/README.md`（8 章の素材の決まり）
