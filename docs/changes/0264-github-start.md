# #264 GitHub のアカウントがない人向けに、GitHub を使えるようにする手順のページを足す（2026-11-02）

- trial.md・setup.md の「用意するもの」は、GitHub のアカウントがあり `gh` でログイン済みであることを前提にしていて、アカウントの作り方・`gh` の入れ方・ログインのしかたがどこにも無かった。PC の素人にも試してもらえるよう、docs/github-start.md（GitHub を使えるようにする）を足した
- 手順は別ページに書き、trial.md の「用意するもの」と setup.md の「1. 使える条件」の `gh` の項目の下から 1 行で誘導した（社長の判断）
- ログインは `! gh auth login` で自分で打つ形にした。ブラウザでの確認が要るため
- 証明書のエラー（`x509` など）の直し方は setup.md の 3 章「`gh issue list` が動かない」にすでにあるので、新しいページからはそこへリンクし、同じ説明を 2 か所に書かないようにした（実装時の判断）
