  - 「最終取得・音」の窓（取得のようす）を右の列から出し、メッセージ窓の上辺の右端に 1 行のタブとして載せる（間取りの `partyWindow.fetchTab`、大きさは `render/map.ts` の `FETCH_TAB`。最大の幅はステージの 50%、高さは 1.6cqw）。下の縁は無く、メッセージ窓につながる。高さは 13 行目を歩く人の足元（448px）より下に収まる
