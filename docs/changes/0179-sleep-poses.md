# #179 ねむっているキャラクターを寝姿の絵にする（2026-10-18）

- 社長の要望: 「ねむる」（暇が 30 分から）とき、ふつうの姿を少し沈めるのをやめ、寝ている絵にする（「Z」は残す）。寝姿は人によっていろいろにし、鼻ちょうちんの人も作る。対象は「ねむる」だけで、かなめ・部門の 6 人・王様・お客さん 2 種の全員。「うとうと」（10 分）は今のまま
- 案の絵を社長に見せて OK をもらい、その絵をそのまま使った。鼻ちょうちんは動かさなくてよいとの判断で、絵に描いてあるもの（ひびき・むすび・王様）をそのまま使い、Canvas では描かない
- 寝姿: かなめ＝座ったままこっくり、みのり＝腕を組んでのけぞる、ひびき＝上を向いて口を開ける（鼻ちょうちん）、ひらめ＝頬杖、ささえ＝腕に突っ伏す、たくみ＝頭の後ろで手を組んでのけぞる、むすび＝首をかしげる（鼻ちょうちん）、王様＝玉座でいびき（鼻ちょうちん）、旅の剣士＝剣を抱えてうつむく、旅の魔法使い＝杖にもたれる。全員正面で座った姿。椅子・机・玉座は絵に描かず、画面の家具に任せる
- 絵: 各キャラのストリップにコマ 7（寝姿）を足し、560×80 から 640×80 にした。`assets/sprites/build_sprites.py` に寝姿のシート（1 人 1 マスの格子）を読む `--sleep`・`--sleep-cols` を足した。寝姿は座って背が変わるので、主シートの縮尺をそのまま使う。作り直したあともコマ 0〜6 の画素は変わらないことを確かめた
- 画面: `idle.ts` の `sleepPose` はコマ 7 を返し、沈み（`IDLE.sleepSinkPx`）をやめた（定数は消した）。「Z」は残す。お客さんの休憩中・待機中（いままでのうなずきと「Z」）もコマ 7 と「Z」にし、うなずきはやめた。コマ 7 の無い狭いシートでは正面（コマ 0）で描く（`spriteArt.frameInSheet`）
- テスト: 寝るときだけコマ 7（うとうと・遊びはコマ 0〜3 のまま）、お客さんの寝姿、`frameInSheet`、10 体の PNG が 640×80 であること（`apps/web/sprite-sheets.test.ts`）
