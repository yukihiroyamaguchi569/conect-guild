# クエストのカードの番号を左の角に移し、担当の行を消し、題名を 3 行まで出す（Issue #302）

- クエスト掲示板で開くカードの左上の丸（締め切りまでの日数）をやめ、そこにクエストの番号を角丸の四角で出すようにした。4 桁の番号（`#1201` など）まで収まる。締め切りは下の巻物の「締め切り」の行で分かる
- 上の帯には題名だけを出し、2 行で切らずに 3 行まで出すようにした（帯の高さに 3 行が収まる）
- 下の巻物から「担当」の行を消した。担当はカードの枠の色と絵で分かる
- 使わなくなった日数の値（`cost`・`costOf`）と、担当の名前・役（`owner.name`・`owner.label`）をカードのデータから外した
