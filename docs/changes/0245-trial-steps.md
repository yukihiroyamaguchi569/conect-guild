# trial.md の作る手順を、利用者がやることの番号付きの手順にする（Issue #245）

- 冒頭の setup.md の「使える条件」へのリンクをやめ、要るもの（Node.js・Claude Code・gh・clone と npm ci・手元の設定が無いこと）を「用意するもの」に直接書いた（社長の指摘）
- 「あなたがやること」を 1〜6 の番号で順に並べた。セルを開く（`! npm run trial:open-cells`）を任意の確かめから外し、ブラウザで開く前の手順としてひとつながりにした。`/guild-trial` がやることは、手順の中に「→ スキル:」の行で入れた（社長の指摘）
- 「片付け」の節を「自分の会社にする（卒業）」の前に移した。「卒業」は分かりにくいので、trial.md・README・setup.md で「自分の会社にする（卒業）」の形にした（社長の判断）
- 「片付け」は「お試しの会社を消したい場合は」で始めた（社長の指摘）
