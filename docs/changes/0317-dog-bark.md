# #317 訪問者が扉から入ってきたら、犬が扉を向いて「わんわん」と吠える（2026-11-27）

- 訪問者（#195）が扉（`SELECTED_LAYOUT.offstage`）から歩き出した時刻から 3 秒（`TRINKETS.visitorBarkMs`）、犬が吠える絵（`bark-poodle`、#316）で、「わん」と同じつぶやきの形の吹き出しで「わんわん」と言う
- 吠える絵は右を向いている。どの間取りでも扉は犬の右にあるので反転しない。扉が犬の左にある間取りなら左右反転する（`barkFlippedIn`）
- 訪問者の状態はループの中（`room.visitors`）にだけあるので、`VisitorStage.comingInSince` で歩き出した時刻を読み、小物の動きの手がかり（`DecorCues.visitorInAt`）に渡す。訪問者のコマはメンバーのコマのあとに決まる（`visitorScene`）ので、`loop.paintAt` で訪問者のコマを決めたあとに足す
- 場面・呼びかけ・halted で訪問者が引き返したら（`cutTrip`）、そこで吠えやむ
- 絵の優先は、回る（#312）、なでている（しっぽを振る）、吠える、紙吹雪で跳ねる（#311）、乾杯（#315）、お言葉を聞く（#314）、遊びに来た人がそばにいる、たまに起きる、寝ている、の順
- 吹き出しの優先は、なでている「わん」、訪問者への「わんわん」、乾杯の「わん！」、寝言の順。halted の間は「わんわん」を出さない。メンバーの頭上の吹き出しと重なるフレームでは出さない（「わん」と同じ）。「わんわん」は「わん」より横に長いので、隣の席のメンバーの吹き出しと重なりやすい
- 効果音・ナレーションは足さない
- DESIGN.md の 8 の小物の動き（ペット）に足した
