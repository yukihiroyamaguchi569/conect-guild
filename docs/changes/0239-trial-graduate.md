# #239 feat: お試しの会社を自分の会社に卒業させるスキル /guild-trial-graduate（2026-10-21）

- お試しの会社（`/guild-trial`）を、そのまま利用者の本物の会社にするスキル `/guild-trial-graduate` を足した。まだ AI の会社が無い人が orchestration.md の 3 章から一式を作るのは重く、お試しの会社は雛形から作った本物と同じ形なので、卒業させれば近道になる（社長の発案）。DESIGN.md の 10 章（お試しの会社のスキルの項目の並び）に 1 項目
- そのまま使い続けると `/guild-trial-cleanup` の対象のままで、本物の仕事ごと消える危険があるため、お試しの印（リポジトリの説明、`CLAUDE.md` の `TRIAL_NOTE` の行）を外し、名前の形と置き場（`~/guild-trial/`）からも外す
- 社長の判断: リポジトリ名とフォルダは新しい会社の名前に変える／部門は卒業では変えない（あとで司令塔に頼む）／`CLAUDE.md` の変更は会社のリポジトリの `main` に直接 commit・push
- 実装時の判断: 説明を最初に変える（片付けはリポジトリを説明で見分けるため）。開いている `npm run dev:all` はスキルが止めず、利用者に止めてもらう（止める理由が卒業の正しさではなく起動し直しのためで、セルを閉じてもらうのと一緒に頼めるため。プロセスを止める操作を増やさない）。前の形 `<日付>-<4 文字>` のお試しは説明が無く、片付けの対象から外す手段が名前を変えるまで無いので、卒業させない
- docs/trial.md に「卒業する」の節、README（日・英）の「架空の会社を作って試す」に 1 行、`/guild-trial` の最後の案内に 1 行を足した
