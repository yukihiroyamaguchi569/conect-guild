# conect-guild

[English](README.en.md)

AI だけで動く小さな会社を、レトロ RPG のギルド画面として眺めるアプリ。

[conect-management](https://github.com/yukihiroyamaguchi569/conect-management) では、司令塔の AI（かなめ）が社長の依頼を GitHub Issue に分解し、部門ごとの Claude Code セッション（経理・広報・企画・総務）に渡して、PR で成果を受け取ります。conect-guild はその様子を、クエスト掲示板・パーティ・玉座の王様として描きます。

![デモモードの画面（架空のデータ）](assets/screenshots/demo-overview.png)

デモモード（架空のデータ）の画面。

| 会社 | ゲーム |
|---|---|
| GitHub Issue（部門ラベル付き） | クエストの巻物 |
| 部門セッション | パーティのメンバー |
| 司令塔（かなめ） | ギルドの受付 |
| 社長（ゆきひろ） | 玉座の王。承認待ちは「承認まち」の吹き出し |
| PR | 宝箱。マージで「最近の成果」に加わる |

## できること

- **Canvas の社屋**: かなめは受付、4 部門は机、王様は玉座にいて、出来事が無い間も小さく動く
- **巻物・宝箱・クリア**: Issue が開くとかなめが巻物を机まで運ぶ（近い机にはときどき投げる）。PR のマージで担当が宝箱を受付に届け、Issue のクローズで「クリアした！」と紙吹雪
- **パーティの状態**: 作業中・確認まち・承認まちなどを GitHub の Issue・PR から出す。MulmoTerminal を使っていれば「いま作業中」「許可待ち」も数秒の遅れで加わる
- **効果音**: Web Audio でその場で鳴らす電子音。初期値は消音で、音量は 3 段階
- **昼夜**: 手元の時刻で部屋の明るさが変わり、夜は灯りの周りだけが明るい
- **暇なとき**: うとうと・寝る、お茶・窓・おしゃべり・玉座のそばのトイプードルと遊びに行く
- **ようすのナレーション**: 出来事が無い間、メッセージ窓がギルドのようすを 20 秒ごとに語る
- **王様の呼びかけ**: 社長がセッションに指示を出すと、王様が話しかけ、相手が「はっ！」と返す
- **経験値とレベル**: クリアとマージの全履歴から数える。レベルアップでは席で跳ねて「LEVEL UP」
- **セリフ**: 巻物の受け渡し・宝箱・クリアのときに短い一言
- **デモモード**: 架空のクエストで一連の演出をくり返す

## デモモードで見る

Node.js 26.10 以上で:

```bash
npm ci --ignore-scripts
npm run dev
```

http://127.0.0.1:5173 を開くだけで、架空のクエストのデモが動きます（collector がまだデータを集めていないあいだの自動のデモ。音は「♪ 音を出す」で鳴ります）。collector も GitHub も要りません。

効果音つきで最初から見る・撮るときは http://127.0.0.1:5173/?demo=1 を開き（昼の部屋なら `?demo=1&hour=12`）、「▶ はじめる」を押します（画面の幅が狭いと押せないので、ウィンドウを広げます）。
